# Phase 3 measured evidence

Generated by `python -m bda.batch.publish`. Datasets are not included.
trials.json contains warmups and every measured outcome; journals preserve original starts/results.
issues.json lists failures/incomplete records without replacing them.
datasets.json records generator inputs/checksums/expected statistics; environments.json and task-metrics.json capture runtime evidence.
Charts show measured medians and observed min/max, not confidence intervals.
See ../../PHASE3_VALIDATION.md for exact commands, limitations and interpretation.

Measured charts: [execution time](charts/execution-time.png),
[throughput](charts/throughput.png), [Spark versus Python](charts/spark-versus-python.png),
[partition configurations](charts/partition-runtime.png), and [storage](charts/storage.png).

The historical-hourly JSON example was independently checked against manifest totals
for Jan 1–3 UTC (end exclusive): 48 hourly rows and 28,426 events. Its separate
execution receipt includes JSON write time and is not a campaign comparison sample.
